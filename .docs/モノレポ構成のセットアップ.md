# npm workspaces を使ったモノレポ構築

1.  ルートディレクトリの作成

    ルートフォルダを作成し、npm init -y で package.json を自動生成する。

    ```bash
    mkdir my-monorepo-1
    cd my-monorepo-1
    npm init
    ```

    実行結果

    ```bash
    package name: (my-monorepo-1)
    version: (1.0.0)
    description:
    entry point: (index.js)
    test command:
    git repository:
    keywords:
    author:
    license: (ISC)
    type: (commonjs)
    About to write to /workspaces/portfolio-nextjs-2/my-monorepo-1/package.json:

    {
        "name": "my-monorepo-1",
        "version": "1.0.0",
        "description": "",
        "main": "index.js",
        "scripts": {
            "test": "echo \"Error: no test specified\" && exit 1"
        },
        "author": "",
        "license": "ISC",
        "type": "commonjs"
    }
    ```

2.  自動生成された package.json にはワークスペースでは不要な項目も含まれるため、手動で削除と必要な項目を追記する。最終的に以下のようにする

    ```json
    {
      "name": "my-monorepo-1",
      "private": true,
      "workspaces": ["apps/*", "packages/*"]
    }
    ```

3.  Next.js アプリの自動生成 (apps)

    Next.js公式の CLI ツールを使って apps/web フォルダ内にアプリを自動生成する。

4.  パッケージの自動生成 (packages)

    ```bash
    npm init -w packages/logger
    ```

    実行結果

    ```bash
    package name: (logger) @my/logger
    version: (1.0.0)
    description:
    entry point: (index.js) ./src/index.ts
    test command:
    git repository:
    keywords:
    author:
    license: (ISC)
    type: (commonjs) module
    About to write to /workspaces/portfolio-nextjs-2/my-monorepo-1/package/logger/package.json:

    {
        "name": "@my/logger",
        "version": "1.0.0",
        "description": "",
        "main": "./src/index.ts",
        "devDependencies": {},
        "scripts": {
            "test": "echo \"Error: no test specified\" && exit 1"
        },
        "author": "",
        "license": "ISC",
        "type": "module"
    }
    ```

5.  自動生成された package.json にはパッケージでは不要な項目も含まれるため、手動で削除と必要な項目を追記する。最終的に以下のようにする。
    ```json
    {
      "name": "@my/logger",
      "version": "1.0.0",
      "private": true,
      "type": "module",
      "main": "./src/index.ts",
      "types": "./src/index.ts",
      "scripts": {},
      "devDependencies": {}
    }
    ```
